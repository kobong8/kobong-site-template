# 검증 기록

2026-10-18, Windows. FastAPI 로컬 실행으로 변경. 기존 Node.js v24.20.0 기반 프런트엔드 검사도 유지.

| 항목 | 결과 |
| --- | --- |
| `npm run check` | JS 모듈 문법 검사 통과 |
| `npm test` | 5개 테스트 통과: 예제 데이터·영구 링크·잘못된 주소·중복 ID·escape/URL 프로토콜·실습 블록 |
| `python -m unittest discover -s tests -p "test_*.py"` | FastAPI 실제 HTTP 응답, 정적 파일 원본 일치, health, 비공개 경로와 없는 파일 404 검사 |
| 브라우저 시각/상호작용 검사 | 미실행. 사용자가 직접 테스트할 수 있도록 아래 항목 제공 |
| 기존 사이트 전체 콘텐츠 이식 | 범위 외. 기존 파일 수정 없음 |
| 배포·커밋·푸시 | 미실행 |

## 브라우저에서 확인할 항목

1. 1440×900, 1280×720에서 랜딩의 두 선택지가 표시되는지 확인합니다.
2. DevOps 발표에서 방향키·Space·Home/End와 이전/다음 버튼을 확인합니다. 첫 장/마지막 장의 경계와 그룹 내 SESSION 번호도 확인합니다.
3. F로 집중 모드를 켜고 Esc로 종료합니다. 전체 화면이 허용되지 않아도 넓은 화면과 종료 버튼을 사용할 수 있어야 합니다.
4. OpenCode 튜토리얼을 스크롤하면서 현재 목차와 URL이 갱신되는지 확인합니다. 긴 장의 중간에서도 목차가 유지되어야 합니다.
5. 같은 장에서 발표/튜토리얼을 전환하고, 직접 링크 새로고침과 브라우저 뒤로/앞으로 이동을 확인합니다.
6. 코드 복사 성공과 권한 거절 시 안내를 확인합니다. 실패 시 원문을 선택해 수동 복사할 수 있어야 합니다.
7. 체크리스트를 선택하고 모드를 전환했을 때 유지되는지 확인합니다. 새로고침하면 초기화되는 것이 의도한 동작입니다.
8. 390px 모바일에서 목차 선택·단일 열 카드·비교표·복사 버튼을 확인합니다. 코드/표 영역 외에 페이지 가로 넘침이 없어야 합니다.
9. Tab으로 본문 바로가기·목차·버튼·상세 펼치기·체크리스트를 조작합니다. 선택 목록과 입력의 키가 발표 이동을 유발하면 안 됩니다.
10. 개발자 도구에서 외부 폰트·CDN·분석 요청이 없는지 확인합니다. 콘솔 오류와 장문 콘텐츠 잘림을 확인합니다.

이 기록은 브라우저 검수나 실제 두 프로젝트의 이식 검증을 완료했다는 의미가 아닙니다.
