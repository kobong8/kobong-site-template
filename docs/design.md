# 디자인과 요구사항 대응

로컬 실행은 SAIF-2026과 동일한 Python/FastAPI/Uvicorn 방식이다. `main.py`는 루트 HTML과 `/assets`, `/content`만 제공한다. 화면은 FastAPI API를 호출하지 않으므로 GitHub Pages에는 기존 정적 파일을 그대로 배포한다. npm 개발 서버는 제거했고 Node.js는 선택적 JS 검사에만 사용한다.

참고: `SAIF-2026/docs/presentation-prd.md`, `presentation-trd.md`, `static/style.css`, `opencode-introduction/PRD.md`, `TRD.md` 및 두 적용 대상의 현재 소스.

SAIF의 남색 목차(#111a30), 밝은 배경(#edf1f8), 청색 강조(#5265de), 흰 카드와 어두운 핵심 메시지를 공통으로 사용한다. 발표자 → 제목 → 부제 → 카드 → 설명 → KEY TAKEAWAY → 탐색 순서를 유지한다. 외부 글꼴과 CDN은 사용하지 않는다.

| 구분 | 발표형 | 튜토리얼형 |
| --- | --- | --- |
| 적용 대상 | lecture-devops | opencode-introduction |
| 탐색 | 한 장씩 교체 | 전체 장을 연속 세로 스크롤 |
| 콘텐츠 | 요약 카드·설명·핵심 메시지 | 요약에 실습 블록 추가 |
| 목차 | 현재 장 강조·그룹 자동 펼침 | 스크롤 위치와 동기화 |
| 키보드 | 방향키·PageUp/Down·Space·Home/End | 일반 스크롤 동작 유지 |
| 강조색 | SAIF 청색 | 청록 |

발표와 읽기 모드는 같은 장에서 전환한다. 발표 이동은 URL을 교체하고 명시적인 튜토리얼 목차 이동·모드 전환은 이력에 추가한다. 수동 스크롤은 이력을 추가하지 않는다. 순서가 바뀌어도 링크가 유지되도록 고정 ID를 사용한다. 그룹 내 SESSION 번호와 전체 번호는 자동 계산한다.

모바일은 선택형 목차와 단일 열 카드로 전환한다. 긴 코드와 표는 해당 영역에서 스크롤한다. 내용 높이를 고정하거나 잘라내지 않는다. 집중 모드의 전체 화면 API가 실패해도 넓은 레이아웃은 유지한다. 입력 요소의 단축키와 버튼·링크·summary의 Space 기본 동작을 존중한다.

OpenCode 문서 최신 변경 기록에 맞춰 인쇄 기능은 제외했다. 실제 11개 장과 명령어 검색·필터 등 제품별 기능을 복제하지 않고 재사용 화면과 축약 예제를 제공한다. 사내 설정값이나 설치판 명령어를 임의로 만들지 않았다. 체크리스트는 현재 페이지 세션의 메모리만 사용한다.
